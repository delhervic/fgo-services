# FGO Services

Página de presentación de FGO (Fractional Growth Operator): servicios, precios, proyectos y contacto.

- `index.html` es la página completa (sin paso de compilación). Fuentes en `fonts/`, imágenes en `img/`.
- Publicada con Cloudflare Pages conectado a la rama `main`: **https://fgo-services.pages.dev**
- Identidad: Sora (títulos) + Inter (texto), azul petróleo #0F3D4A, teal #1B7A7A, lima #A3E635 solo como acento. Logo extraído del archivo maestro, no redibujado.
- Revisión antes de publicar: `node qa.mjs index.html <carpeta-capturas>` (herramienta del repo `demos`).
